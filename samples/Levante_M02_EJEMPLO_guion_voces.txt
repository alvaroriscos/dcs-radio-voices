# FORMATO DE CADA LÍNEA:
#   HABLANTE NNN (tono) [EFECTO] ~duración_estimada : texto en inglés
# - Numeración NNN global y única en toda la misión (sirve para nombrar
#   los .ogg al cortar: "HABLANTE NNN palabra Ns.ogg").
# - Efectos: [AIR] radio aire-aire · [GROUND] personal de tierra ·
#   [TOWER] controlador/ATIS · [CLEAN] sin efecto · [STRESS] radio con estrés.
# - Las líneas de PLAYER son las pregrabadas del menú F10.
# - Todo en orden cronológico exacto. Los números van deletreados
#   (estilo radio) para que la voz los lea bien.
#
# HABLANTES (voces recurrentes marcadas con *):
#   PLAYER*  = Talud One-One (piloto, líder, jugador)
#   WING*    = Talud One-Two (ala, joven y espontáneo)
#   ATIS     = Rene Mouawad Information (plano)
#   GROUND   = Rene Mouawad Ground
#   TOWER    = Rene Mouawad Tower
#   DEP      = Beirut Departure/Arrival (procedimental)
#   ATALAYA* = Atalaya Control, JOC de la misión (frío y conciso)
#   LOBO6    = jefe de sección en tierra en la LZ (cansado, tenso)
#   MEDIC    = sanitario en la LZ (urgente)
#   TOWER2   = Rene Mouawad Tower en el regreso (misma voz que TOWER)
#
# DATOS INVENTADOS DE LA MISIÓN (ajustar en el .miz):
#   Aeronaves: 2 x AS532 Cougar · Indicativo flight: TALUD (11 y 12)
#   Inicio: 06:30 local (03:30Z) · Viento desde 270/08 kt (en el .miz: 090)
#   QNH 1014 · T 22 / Td 11 · Few 4000 ft · Vis 10 km+
#   Misión: transporte de 8 pax + carga ligera a FOB Atalaya (LZ "Pelícano"),
#           incidente en la LZ (herido) y regreso.
#   Presets (kneeboard):
#     PRI 1 UHF 251.000 Atalaya Control (misión)
#     PRI 2 UHF 277.000 ATIS
#     PRI 3 UHF 250.100 Tower
#     PRI 4 UHF 250.300 Ground
#     PRI 5 UHF 253.500 Departure / Arrival
#     AUX 1 VHF 143.200 Tactical (flight)
#     AUX 7 VHF 140.100 Guard / Emergencia
#   Flags previstos: RAMP_GO, TAXI_GO, TKOF_GO, TRANSIT_GO, LZ_INBOUND,
#                    LZ_ON_GROUND, CASEVAC_REQ, MANPADS_WARN, RTB_GO, LAND_GO
